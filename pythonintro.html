How to study each week

  1. Watch the lecture (Course tab has the link). Pause and type along with the examples instead of only watching.
  2. Learn tab: run and edit every example, then answer the "Check yourself" questions without running code first.
  3. Practice tab: write each problem yourself. Use Try it to type your own inputs, then Run checks. Open a nudge only after 15 minutes stuck.
  4. Submit on cs50.dev: copy your code into the matching file, run check50, then submit50. The exact commands are on each official problem page. Tick Submitted here.
  5. Notes tab: write two lines on what confused you. Re-read them before the next week.

The checks on this page are my own and are close to CS50's, but only check50 and submit50 count toward your certificate.

Pacing plan to finish by Dec 31

About 6–8 hours a week. Lighter weeks line up with your ISYE 6501 Midterm 2 (closes Nov 22) and final (closes Dec 13). If you fall behind, keep going: the official FAQ explains what happens to unfinished work after the deadline.

Backup and transfer

Getting set up (one time)

From the Problem Set 0 page. You don't need to install Python on your computer for submitting; cs50.dev is VS Code in the browser.

  1. Submit the short form linked on Problem Set 0.
  2. Follow the link there, log in with GitHub, authorize CS50, tick the box that gives staff access to your submissions, and click Join course.
  3. Log in to cs50.dev. Close any Welcome tabs.
  4. In its terminal, run update50. Click Rebuild now if asked.
  5. For each problem: mkdir and cd into a folder named as the problem page says, create the file with code name.py, paste your code, then run the check50 and submit50 commands from that page.
  6. Check your scores at cs50.me/cs50p.

Academic honesty: CS50 allows its own AI helper (the CS50 Duck at cs50.ai) but not other AI tools for writing pset code. The nudges on this page point to concepts and never give code. Read the policy linked in Resources.
