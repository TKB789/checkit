Course at a glance

Based on the Fall 2026 syllabus. Expect the same structure in the term you take.

  • Format: Graduate-level, about 9–12 hours a week on average (4–5 for strong programmers, 15+ for those catching up).
  • Language: Python, in Jupyter notebooks hosted on Vocareum with autograding.
  • Grading: Notebooks 50% (roughly one per week). Exams 50%: Midterm 1 (10%), Midterm 2 (15%), Final (25%).
  • Exams: Timed, proctored, open-book and open-internet, but no AI tools and no help from people.
  • Deadlines: Everything is due at 11:59 UTC. Notebooks get a 48-hour grace period, then half credit until the next exam.

Module 0: Fundamentals

  • Topic 0: Course and co-developer intros
  • Topic 1: Python bootcamp review + intro to Jupyter
  • Topic 2: Pairwise association mining (defaultdict, asymptotic running time)
  • Topic 3: Mathematical preliminaries (probability, calculus, linear algebra)
  • Topic 4: Representing numbers (floating-point arithmetic, numerical analysis)

Module 1: Representing, transforming, and visualizing data

  • Topic 5: Preprocessing unstructured data (strings, regular expressions)
  • Topic 6: Mining the web (HTML processing, web APIs)
  • Topic 7: Tidying data (pandas, merge/join, melt and cast)
  • Topic 8: Visualizing data and results (Seaborn, Bokeh)
  • Topic 9: Relational data (SQL)

Module 2: The analysis of data

  • Topic 10: Intro to numerical computing (NumPy, SciPy)
  • Topic 11: Ranking relational objects (graphs as sparse matrices, PageRank)
  • Topic 12: Linear regression (QR decomposition, least mean squares)
  • Topic 13: Classification (logistic regression, numerical optimization)
  • Topic 14: Clustering (k-means)
  • Topic 15: Compression (PCA, SVD)

Bootcamp (optional but strongly recommended)

Live sessions, Tuesday/Thursday evenings in the fall term. Recordings are usually posted within a day.

  • Before Midterm 1: dictionaries, comprehensions, math as code, nested data, lambda and sorting, problem-solving method, regex.
  • Before Midterm 2: pandas (loc/iloc, merge, groupby), SQL (aggregates, CASE, subqueries, CTEs, window functions), NumPy (arrays, boolean masks, sorting, matrix multiplication, broadcasting).
  • Before the Final: review of the full course.

Exams and deadlines

Fall 2026 reference dates. Your term's dates will differ.

  • Midterm 1: Oct 2–7 window
  • Midterm 2: Nov 6–11 window
  • Final exam: Dec 11–16 window

Recommended outside resources

Most of these are the ones the course itself recommends, plus a few I'd add. Free unless noted.

Python

  • A Whirlwind Tour of Python, Jake VanderPlas. Free, the course's first recommended reference.
  • Python Tutor. Step through code and watch variables change. Excellent for dicts and loops.
  • Codewars. Short drills. Start with the 6-kyu problems on the course's self-test list.
  • w3resource Python exercises. Practice sets by topic.
  • CS50P (your other tracker page). Weeks 0–3 and 7 cover the Python core, exceptions, and regex this course assumes.

Pandas, NumPy, and data

  • Python Data Science Handbook, Jake VanderPlas. Free online, covers NumPy, pandas, and more.
  • Python for Data Analysis, Wes McKinney. The course's recommended book. Free to Georgia Tech students through the library.
  • NumPy broadcasting guide. Official and clear.
  • Pandas cheat sheet. Good visuals of what each operation does.

SQL

  • SQLZoo. Free, interactive, and in the course's bootcamp list.
  • W3Schools SQL. Quick reference for syntax.

Regex

  • regex101. Test patterns live with explanations. Choose the Python flavor.
  • Regex Tuesday. 20 challenges with test cases.

Math

  • 3Blue1Brown: Linear Algebra, and the calculus series on the same site. Best visual intuition, free.
  • LAFF: Linear Algebra Foundations to Frontiers. Free PDF with exercises. Recommended by the course.
  • StatQuest with Josh Starmer (YouTube). Statistics, regression, and ML explained step by step.
  • MIT OCW: Probability and Statistics. Free readings and notes.

Floating point and numerics

  • What Every Computer Scientist Should Know About Floating-Point Arithmetic. The course's recommended reference.
  • IEEE 754 float converter.

Practice and reference for this course

  • The official CSE 6040 site. Syllabus, bootcamp schedule, and exam practice are here once the course is running.
  • Bootcamp notebooks (GitHub). Public material from the course's bootcamp, which you can run in Google Colab.

Coming from outside the program?

  • CS 1301x: Computing in Python I (edX). Georgia Tech's intro Python course. The syllabus says students who struggled before did well after taking it.
