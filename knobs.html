k in k-nearest neighbors

M2 L8 · KNN

Each shaded cell takes the majority class of its k nearest training points. Small k follows every point; large k smooths the boundary.

Try this
  • k = 1: training accuracy is 100% (each point is its own nearest neighbor), but validation is lower. That gap is overfitting.
  • Raise k until validation stops improving; very large k blurs the two groups together.

λ in a soft-margin SVM

M2 L4 · Support vector machines

Minimize (errors) + λ·Σaⱼ². A bigger λ cares more about a wide margin and accepts more points inside it or on the wrong side.

y = +1y = −1solid = classifier, dashed = margins
Margin width Inside the margin Wrong side
Try this
  • Slide λ up: the margin widens and more points fall inside it.
  • Software such as R's ksvm uses C the other way round: a big C acts like a small λ (narrow margin, fewer training errors).

α in exponential smoothing

M7 L1–L2 · Exponential smoothing

Sₜ = α·xₜ + (1 − α)·Sₜ₋₁. The series has noise and a real jump at period 35.

observedsmoothed Sₜ
One-step error (MAE) Catches the jump after
Try this
  • Small α trusts the baseline: a calm line, but slow to catch the jump.
  • α = 1 copies the last value: no smoothing at all, every bump passes through.

C and T in CUSUM

M6 L2 · CUSUM

Sₜ = max{0, Sₜ₋₁ + (xₜ − μ − C)}, alarm when Sₜ ≥ T (then S restarts at 0). μ = 20; the true mean moves to 21.5 at period 40.

Sₜthreshold T, alarmsgray line = real change
False alarms before the change First alarm after the change
Try this
  • Lower C or T: the change is caught sooner, but false alarms appear.
  • Raise them: fewer false alarms, slower detection. Pick by which mistake costs more.

λ in lasso (and ridge)

M11 L2 · Variable selection

Minimize (squared error) + λ·penalty on the coefficients. Five scaled predictors; only x₁–x₃ really matter. A bigger λ is the same as a smaller budget τ.

fitted coefficienttick = true value
Nonzero coefficients Validation error (MSE)
Try this
  • Lasso: as λ grows, the useless x₄ and x₅ hit exactly 0 first; then x₃.
  • Ridge: everything shrinks toward 0 but nothing reaches it, so ridge doesn't select.
  • Watch the validation error: a little shrinkage often helps, too much hurts.

The classification threshold

M10 L5 · Confusion matrix and cost

Try this
  • Lower the threshold: more positives caught (sensitivity ↑) but more false alarms (specificity ↓).
  • Make a missed positive expensive and the cheapest threshold moves down. Accuracy alone would pick a different threshold.
  • The ROC curve and its AUC don't change as you slide; only your point on the curve moves.
